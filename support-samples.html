Sample 3"It doesn't work"

A ticket with no details

There is nothing to reproduce yet. The reply asks four short questions and gives the two fixes that solve most browser cases.

Ticket from Alex · Subject: (no subject)

app doesnt work. fix it

Reply

Subject: Re: your message to Tidyflow Support

Hi Alex,

Let's get this working. I can't tell yet what's going wrong, so a few details would help. Short answers are fine:

  1. What were you trying to do (for example, send an invoice)?
  2. What happened instead: an error message, a blank screen, a loading wheel? A screenshot is ideal, or copy the message text.
  3. Are you using the web app (which browser?) or the phone app?
  4. Did it work before? If yes, when did it stop?

In the meantime, two things fix a lot of cases: reload the page with Ctrl+F5 (Cmd+Shift+R on Mac), and try an incognito window. If it works there, an extension or the cache is the cause, and I'll walk you through the fix.

Reply to this email and I'll continue from your answers.

Davyd
Tidyflow Support

Four questions at most, each one answerable in a few words. The customer gets something to try while they answer.

Sample 4Help-center article

I didn't get the password reset email

The kind of article a support team links in a reply. Written so that someone in a hurry can fix it in one minute.

I didn't get the password reset email

Applies to: Tidyflow web app, all plans. Takes about 2 minutes.

Try this first

  1. Wait 10 minutes. The email can be slow when many people request one at the same time.
  2. Check Spam, Junk and "Promotions". Look for a message from no-reply@tidyflow.example.
  3. Check the address. Open the reset page again and make sure it is the same address you signed up with, with no typo and no extra space.

Still nothing?

  • Several addresses: if you have more than one, try each of them. We only send the email to an address that has an account.
  • Company mailbox: some company filters block automatic emails. Ask your IT team to allow tidyflow.example, then request the reset again.
  • Too many attempts: after 5 requests in an hour we pause the reset for 60 minutes. Wait, then try once more.

Good to know

The reset link works for 60 minutes and only once. If you request several emails, use the latest one, because the older links stop working.

Contact support if none of this helps. Send us the email address on the account and the time of your last attempt, and we'll check it from our side. We never ask for your password.

Sample 5Bug report

The CSV export is empty across a year boundary

What Sample 2 turned into after reproducing it. It is written so a developer can reproduce it without asking me anything.

[Invoices] CSV export returns a file with only the header row when the date range spans two years

EnvironmentWeb app v2.14.3, Chrome 126, macOS 14.5, Pro plan
Linked ticket#10482 (customer Tom R.)
SeverityMajor. Data is not lost, but year-end reports can't be exported. Priority: high, because year-end is close.
Reproducible5 out of 5 attempts

Steps

  1. Log in and open Invoices → Export → CSV.
  2. Set the range to 15 Dec 2025 – 15 Jan 2026.
  3. Click Export.

Expected: a CSV with all 42 invoices from the range.

Actual: the file downloads and contains the header row only. No error message is shown.

What I checked

  • 15 Nov – 15 Dec 2025 works (38 rows). 1 Jan – 31 Jan 2026 works (31 rows). Only ranges across 31 Dec / 1 Jan fail.
  • The browser console shows a failed request to /api/export (HTTP 500). Request ID: 7f3a-91c2.
  • Other browsers: Firefox 127 behaves the same, so it is not Chrome specific.

Workaround for customers: export the two years as two separate ranges, or use Print → Save as PDF.

Attachments: screenshot of the empty file, HAR file, the test range as a link.

Everything a developer needs is above the fold: environment, exact steps, expected against actual result and the boundary that narrows down the cause. The workaround goes back into the customer's ticket.
